**Skyfold 1.0.14 (public beta): clearer recent activity.**

> On 1.0.10 or later? Skyfold offers this update by itself: Settings → About → *Check for updates* → *Update now*.

### Changed
- **Recent activity says what happened.** Each entry in the panel now shows, under the file name, what Skyfold did and where: *Deleted in iCloud · iCloud Drive/Downloads*, *Downloaded*, *Uploaded*, and for a rename the new name with the old one. Before, only the file name was shown.

Full list: [CHANGELOG](https://github.com/zoranmod/skyfold/blob/main/CHANGELOG.md).

### Download
`Skyfold-windows.zip` below; unzip anywhere and run `Skyfold.exe` (or replace your existing Skyfold folder; settings and sync state are kept). Check it with `Skyfold-windows.zip.sha256`, or with `gh attestation verify Skyfold-windows.zip --repo zoranmod/skyfold`. Windows SmartScreen may warn about a new, unsigned app: *More info → Run anyway*.
