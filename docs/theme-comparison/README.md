# Theme comparison

Real Skyfold widgets rendered on Windows with the Fusion style, and real exported Notes indexes opened in offline Microsoft Edge. Each pair uses the same invented account, activity and notes. The panel is 376 × 535, Settings is 680 × 540, and the browser viewport is 1180 × 800. System resolved to Light for these captures. System following a dark preference was checked separately.

The nine pairs for the existing themes are pixel-identical. Settings offers OLED as the fourth choice, labelled **OLED (crna)** in Bosnian. The existing Notes toggle cycles through Light, Dark and OLED. A saved browser preference takes priority over the app preference supplied at export. With the app set to System and no browser override, the page follows the browser’s color-scheme preference.

Changing the app preference updates the index and eligible pages on a subsequent Notes sync. The page digest, read-only check and restyle journal still protect personal edits. The stylesheet and index layout versions both increased to 3. The Notes content format and image quality versions stayed the same.
